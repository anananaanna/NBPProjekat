Backend postavka

Otvorite terminal u korenu projekta:

Bash
cd backend
npm install

Zavisnosti koje se instaliraju: 
- Instalacija Express-a i osnovnih alata
npm install express cors dotenv nodemon
- Instalacija drajvera za baze podataka
npm install neo4j-driver redis redis-om
- Instalacija za upload slika i rad sa putanjama
npm install multer path
- Instalacija za real-time notifikacije (Socket.io)
npm install socket.io

Konfiguracija environment fajla:

U backend folderu kreirajte fajl .env i unesite:
PORT=3001
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password123
REDIS_URL=redis://localhost:6379
JWT_SECRET=your_super_secret_jwt_key_here


Client (Frontend) postavka

Otvorite novi terminal:

Bash
cd client
npm install

Zavisnosti:
- Instalacija React Router-a za navigaciju
npm install react-router-dom
- Instalacija Axios-a za komunikaciju sa API-jem
npm install axios
- Instalacija klijenta za notifikacije
npm install socket.io-client
- Instalacija ikonica (ako ih koristiš, npr. Lucide)
npm install lucide-react


Dockerizacija (Docker Desktop):

Redis container:
docker run -d --name redis_project -p 6379:6379 redis:latest

Neo4j container:
docker run -d \
    --name neo4j_project \
    -p 7474:7474 -p 7687:7687 \
    -e NEO4J_AUTH=neo4j/password123 \
    -e NEO4JLABS_PLUGINS='["apoc"]' \
    neo4j:latest


Pokretanje aplikacije:

Backend:
U backend folderu: npm start (server sluša na portu 3001).

Frontend:
U client folderu: npm start (aplikacija se otvara na localhost:3000).

Inicijalizacija podataka:
Otvorite Neo4j Browser, iskopirajte sadržaj fajla baza.txt i pokrenite ga.
